# Discrete-and-non-linear-automatic-control-theory
Репозиторий с лабораторными работами по курсу "Дискретные и нелинейные системы автоматического управления"

Это учебные материалы, выполненные в рамках курса по дискретным и нелинейным системам автоматического управления. Используйте информацию из этого репозитория как справочный материал, а не для прямого цитирования.

## Список лабораторных работ:
1. ЛР 1. Моделирование дискретных систем
2. ЛР 2. Моделирование дискретной системы с ПИД-регулятором (ПСР-регулятором)
3. ЛР 3. Исследование типичных нелинейностей
